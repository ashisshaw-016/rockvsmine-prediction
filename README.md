# 🪨 Rock vs Mine Prediction using Machine Learning

## 📌 Project Overview

This project focuses on classifying underwater objects as either rocks or mines using sonar signal data and Machine Learning techniques. The model analyzes sonar returns reflected from objects and predicts whether the detected object is a rock or a mine.

## 🎯 Objective

To develop a classification model that accurately distinguishes between rocks and mines based on sonar signal characteristics, demonstrating the application of Machine Learning in defense and underwater object detection.

## 📊 Dataset

The dataset consists of:

* 60 Sonar Signal Features
* Frequency-Based Signal Measurements
* Target Variable:

  * R = Rock
  * M = Mine

The model successfully classifies sonar signals into rock or mine categories with high accuracy, showcasing the effectiveness of Machine Learning in pattern recognition and classification tasks.
